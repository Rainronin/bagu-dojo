# 八股训练场

一个基于个人前后端八股题库的静态四选一练习站。前端按 Vue、React、JavaScript、CSS 等分类，后端按 Java、Spring、MySQL、Redis 等分类；每次练习随机抽题，答对或答错都会显示题库原文解析。

## 功能

- 前端 / 后端分域，细分到 Vue、React、Java、MySQL 等科目，并提供跨分类随机练习。
- 四选一作答，即时判定；答对/答错都展示原文解析、代码高亮和逐项错因。
- 每轮题目随机且不重复，未做过的题优先；支持 10 题、20 题或全部。
- 错题本、答题统计、连续练习天数，进度保存在浏览器本地。
- 50 道 JavaScript 手写题阅读模式，不计入选择题进度。
- 深色/浅色主题、键盘操作、手机端适配和顺滑动效。

## 内容

- 前端题库来自个人整理的 Markdown 笔记。
- 后端题库来自「小林coding」Java / Spring / MySQL / Redis 等 PDF 资料，仅提取文本层。
- 当前包含 1043 道选择题和 50 道手写题，覆盖 24 个分类。

## 说明

题库解析保留原文；四选一的干扰项与逐项错因由 AI 基于原文生成，仅供学习使用。题库内容版权归原作者，本项目不用于商业用途。
